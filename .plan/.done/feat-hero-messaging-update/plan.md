# Hero Messaging Update

## Overview

Update hero copy to make value proposition immediately obvious within 3-5 seconds. Target audience: executives and business leaders, not software engineers.

## Changes

### Headline
- Before: "Revenue leaks hide everywhere." / "I find them. I fix them."
- After: "Your operation is losing money." / "You just can't see where."

### Supporting Copy
- Before: "If your platform isn't running, it's costing you money. I fix that."
- After: "Operational bottlenecks quietly cost organizations money. I diagnose the root cause, eliminate it, and build systems that prevent it from coming back."

### Secondary CTA
- Before: "View Case Studies"
- After: "Explore Case Studies"

## Design Direction

- Copy is focal point
- Typography and spacing create confidence
- Photography supports rather than competes with the story

## Tone

Visitor should think: "This person understands operations, finds expensive problems, and builds systems that permanently solve them."

## File Modified

- `content.config.ts` (lines 11-22)

## ADR Review

**ADR-003 (Content-Driven Architecture):** All content centralized in `content.config.ts`. This change follows the established pattern.
